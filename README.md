# Prima+ Interview Task

Fork this repository and complete task.

## Task

Create an end-to-end test for user profile creation.
Output should be a repository with a setup guide in the README.

## Setup

- Node.js 18+ (verified with Node 18.17)
- `npm install`
- Copy `cypress.env.example.json` to `cypress.env.json` and fill in valid credentials (`QA_EMAIL`, `QA_PASSWORD`) for an account with API access to profiles.
- Run headless tests: `npx cypress run --spec cypress/e2e/profile.cy.ts --browser chrome --headless`
- GUI run for local debugging: `npx cypress open --e2e`

## Criteria

- **Functionality** – test successfully creates and verifies a profile
- **Code Quality** – clean, readable and maintainable code
- **Cleanup** – proper cleanup after test

## Test Scenario

- The script signs in using credentials from `cypress.env.json`.
- On the profiles page it creates a new profile with a random name (generated by [faker.js](https://github.com/faker-js/faker)).
- It selects gender, chooses the birth year 1986, and sets PIN `1234`.
- It asserts the newly created profile is visible.
- In `afterEach`, all profiles are removed via the Gateway API to return the account to a clean state.

## Time Limit

Recommended implementation time: **60 minutes**
